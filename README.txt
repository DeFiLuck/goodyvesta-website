# Goodyvesta Version 1

This is a standalone static starter for Goodyvesta, based on the structure/content of the current Goodyvesta website.

Included:
- Home
- Properties
- Updates / Journal
- About
- Contact
- Search and filters
- Enquiry form
- Newsletter UI
- WhatsApp enquiry flow
- Responsive mobile/desktop layout

Important:
- Replace the placeholder phone number +2340000000000 with Goodyvesta's real WhatsApp/phone number.
- Replace hello@goodyvesta.com if a different email is preferred.
- Property cards currently use placeholder visuals/content until real property photos and details are supplied.
- Forms are front-end only; the WhatsApp enquiry works by opening WhatsApp. A real email/database form can be connected later.
- This version contains no user accounts, agent accounts, dashboard, payments, or admin system.

Open index.html in a browser to preview locally.
